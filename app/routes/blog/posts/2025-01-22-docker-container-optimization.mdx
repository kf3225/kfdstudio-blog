# Docker コンテナの最適化

Dockerコンテナを最適化することで、デプロイ時間とコストを大幅に削減できます。

## マルチステージビルド

マルチステージビルドを使用すると、ビルド時の依存関係と実行時の依存関係を分離できます。

```dockerfile
# ビルドステージ
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 実行ステージ
FROM node:18-alpine AS runner
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
COPY package*.json ./
EXPOSE 3000
CMD ["npm", "run", "start:prod"]
```

## レイヤーの最適化

Dockerのレイヤーを効率的に使用することで、ビルド時間を短縮します。

```dockerfile
# 悪い例：頻繁に変更されるファイルを先にコピー
COPY . .
RUN npm install
RUN npm run build

# 良い例：依存関係を先にインストール
COPY package*.json ./
RUN npm ci --only=production
COPY . .
RUN npm run build
```

## .dockerignoreの活用

不要なファイルを除外することで、ビルドコンテキストを小さくします。

```
node_modules
npm-debug.log
.git
.gitignore
Dockerfile
docker-compose.yml
README.md
*.test.js
coverage
dist
```

## ベースイメージの選択

Alpine Linuxなどの軽量なベースイメージを使用します。

```dockerfile
# 通常のNode.jsイメージ（約900MB）
FROM node:18

# Alpineベース（約120MB）
FROM node:18-alpine

# さらに小型のDistroless（約80MB）
FROM gcr.io/distroless/nodejs18
```

## 依存関係の管理

開発時の依存関係を本番環境から除外します。

```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM node:18-alpine
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
COPY package*.json ./
RUN npm prune --production
EXPOSE 3000
CMD ["node", "dist/index.js"]
```

## キャッシュの活用

BuildKitのキャッシュマウントを使用して、ビルド時間を短縮します。

```dockerfile
# syntax=docker/dockerfile:1
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN --mount=type=cache,target=/root/.npm npm ci
COPY . .
RUN npm run build
```

## 複数のビルド引数を使用

柔軟なビルドのために引数を使用します。

```dockerfile
ARG NODE_VERSION=18
ARG ENVIRONMENT=production

FROM node:${NODE_VERSION}-alpine
ARG ENVIRONMENT
ENV NODE_ENV=${ENVIRONMENT}
```

ビルド時の指定:

```bash
docker build --build-arg NODE_VERSION=16 --build-arg ENVIRONMENT=development .
```

## ヘルスチェック

コンテナの健康状態を監視します。

```dockerfile
HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
  CMD curl -f http://localhost:3000/health || exit 1
```

## まとめ

Dockerコンテナの最適化には、マルチステージビルド、レイヤー最適化、適切なベースイメージの選択など多くのテクニックがあります。これらを組み合わせることで、効率的なコンテナ環境を構築できます。
