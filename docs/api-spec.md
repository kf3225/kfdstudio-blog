# API仕様書

このドキュメントでは、KFD Studio BlogのAPIエンドポイントを説明します。

---

## エンドポイント

### 検索 API

#### GET /api/search

記事を検索します。クエリパラメータで検索語句を指定します。

#### リクエストパラメータ

| パラメータ | タイプ | 必須 | 説明     |
| ---------- | ------ | ---- | -------- |
| q          | string | はい | 検索語句 |

#### レスポンス

成功した場合、検索結果の配列を返します。

---

## データ構造

### 記事オブジェクト

記事オブジェクトには以下のフィールドが含まれます：

- id: 記事ID（ファイル名: YYYY-MM-DD-slug）
- slug: 記事のスラッグ（URLに使用）
- title: 記事タイトル
- description: 記事説明
- content: 記事本文（Markdown）
- pubDate: 公開日（ISO 8601）
- updatedDate: 最終更新日（ISO 8601）
- tags: タグ配列

---

## エラーレスポンス

### 共通エラー

エラーレスポンスにはエラーメッセージと詳細が含まれます。

### 記事が見つからない

指定された記事が見つからない場合、404 Not Foundステータスコードが返却されます。
